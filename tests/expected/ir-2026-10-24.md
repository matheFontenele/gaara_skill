## 3. Comandos

```bash
docker run --rm --network none \
  -v /home/matheus/skills/segurity:/skill:ro \
  -v "$HOME/gaara-ir-fixtures/malicioso":/alvo:ro \
  python:3.12-slim bash /skill/scripts/ir_triage.sh --root /alvo

docker run --rm --network none \
  -v /home/matheus/skills/segurity:/skill:ro \
```
